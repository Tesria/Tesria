# Tailscale logo

The Tailscale wordmark, unmodified, from Tailscale's own brand toolkit
(the media kit on tailscale.com/press, October 2025 edition), in black for
light backgrounds and white for dark ones, and the square icon
(`tailscale-icon.png`, the kit's black "squircle"), which reads on both. Used only to name Tailscale where
Tesria documents or shows its optional Tailscale sidecar (dev-plan 19).

Tailscale and the Tailscale logo are trademarks of Tailscale Inc. Tesria is
not affiliated with, sponsored by or endorsed by Tailscale.

Tailscale's logo rules, as the owner checked them (2026-09-24): the logo
may name an integration in dashboards and documentation; it is never used
as Tesria's own branding or in a way that suggests Tailscale made or
endorses Tesria; it keeps clear space around it and its own colors and
proportions, which is why these files are used as supplied.
